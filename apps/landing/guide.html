User Guide

Getting started with
@aimata-dsl/core

Everything you need to compress, expand, parse, and compile UI components using the Aimata micro-DSL.

v0.1.0 MIT 0 dependencies Node ≥ 18 · Browser · Deno · Bun

Installation

npm install @aimata-dsl/core
pnpm add @aimata-dsl/core
yarn add @aimata-dsl/core
bun add @aimata-dsl/core
ℹ
ESM only. The package uses type: "module". For CommonJS projects, use dynamic import() or a bundler.

Quick Start

Import the two main functions and you're ready to go:

import { compressToDSL, expandFromDSL } from '@aimata-dsl/core';

// 1. Take any JSX or HTML string
const jsx = `
  <button
    className="px-4 py-2 bg-blue-500 text-white rounded hover:bg-blue-600"
    onClick={handleClick}
  >
    Submit
  </button>
`;

// 2. Compress → micro-DSL (2-3× fewer tokens)
const dsl = compressToDSL(jsx);
// → '[button.px-4.py-2.bg-blue-500.text-white.rounded.hover:bg-blue-600{onClick=handleClick}|Submit]'

// 3. Expand back to React JSX
const reactCode = expandFromDSL(dsl, 'react');
// → '<button className="px-4 py-2 bg-blue-500 ..." onClick={handleClick}>Submit</button>'

// 4. Or expand to plain HTML
const htmlCode = expandFromDSL(dsl, 'html');
// → '<button class="px-4 py-2 bg-blue-500 ..." data-onclick="handleClick">Submit</button>'

DSL Syntax

The Aimata micro-DSL encodes component trees in a compact bracket notation:

[tag#id.class1.class2{prop1=val1,prop2=val2}|children or [nested]]
PartSyntaxExampleNotes
tag[div|...][button|...]Any HTML tag or PascalCase component name
#id[div#hero|...][section#intro|...]Maps to id="..." — optional
.classes[div.flex.gap-4|...][p.text-sm.text-gray-500|...]Dot-separated, full Tailwind supported
{k=v}{onClick=fn,type=submit}{href=/,target=_blank}Comma-separated key=value pairs
|[div|Hello][div|[span|text]]Children — text or nested DSL nodes
💡
All parts except tag are optional. [div] is valid — it produces <div />.

API — compressToDSL()

compressToDSL(code: string): string

Converts a JSX or HTML string into Aimata micro-DSL. Internally runs parse() then serializes the AST.

Parameters

ParamTypeRequiredDescription
codestringYesA JSX or HTML source string. Must be non-empty and well-formed.

Returns

A compact micro-DSL string. For multiple root nodes, each is newline-separated.

Throws

ErrorCondition
TypeErrorcode is not a non-empty string
SyntaxErrorUnclosed tag encountered during tokenization
 
import { compressToDSL } from '@aimata-dsl/core';

// Simple element
compressToDSL('<div className="flex">Hello</div>');
// → '[div.flex|Hello]'

// With ID
compressToDSL('<section id="hero" className="py-20"></section>');
// → '[section#hero.py-20]'

// Nested children
compressToDSL('<ul><li>One</li><li>Two</li></ul>');
// → '[ul|[li|One][li|Two]]'

// Error handling
try {
  compressToDSL('');
} catch (e) {
  console.error(e.message); // TypeError: compressToDSL expects a non-empty string
}

API — expandFromDSL()

expandFromDSL(dsl: string, targetFramework?: 'react' | 'html'): string

Expands an Aimata micro-DSL string back into production-ready source code.

Parameters

ParamTypeDefaultDescription

targetFramework'react' | 'html''react'Output format

Output differences by target

Feature'react''html'

Event handlersonClick={handler}data-onclick="handler"
Boolean propsdisableddisabled
PascalCase tagsKept as-is (<Button>)Lowercased to <div>

import { expandFromDSL } from '@aimata-dsl/core';

const dsl = '[button.px-4.py-2.bg-blue-500{onClick=go,type=submit}|Click me]';

// React output
expandFromDSL(dsl, 'react');
// → '<button className="px-4 py-2 bg-blue-500" onClick={go} type="submit">Click me</button>'

// HTML output
expandFromDSL(dsl, 'html');
// → '<button class="px-4 py-2 bg-blue-500" data-onclick="go" type="submit">Click me</button>'

// Default is 'react'
expandFromDSL(dsl);
// → same as expandFromDSL(dsl, 'react')

API — parse()

parse(source: string): ASTNode[]

Tokenizes and parses a JSX/HTML string into a plain-object AST. Useful for analysis, class extraction, or building custom transformers.

ASTNode shape

// ASTNode (TypeScript-style for reference)
{
  type:     'element' | 'component' | 'text',
  tag:      string,           // 'div', 'Button', etc.
  id:       string | null,   // from id="" attribute
  classes:  string[],         // from className / class
  props:    Record<string, string>, // all other attributes
  children: ASTNode[],        // nested nodes
  raw:      string,           // original source for debugging
}
import { parse } from '@aimata-dsl/core';

const ast = parse(`
  <div id="card" className="rounded-xl p-6">
    <h2 className="font-bold">Title</h2>
  </div>
`);

// ast[0] →
{
  type: 'element',
  tag: 'div',
  id: 'card',
  classes: ['rounded-xl', 'p-6'],
  props: {},
  children: [{
    type: 'element', tag: 'h2',
    classes: ['font-bold'],
    children: [{ type: 'text', value: 'Title' }]
  }]
}

// Extract all classes recursively
function allClasses(nodes) {
  return nodes.flatMap(n =>
    n.type === 'text' ? [] : [...n.classes, ...allClasses(n.children)]
  );
}
allClasses(ast); // ['rounded-xl', 'p-6', 'font-bold']

API — compile()

compile(ast: ASTNode[], options?: { target: 'dsl' | 'react' | 'html' }): string

Compiles an AST (from parse()) to any output format. Use this when you already have an AST and want to skip re-parsing.

import { parse, compile } from '@aimata-dsl/core';

const ast = parse('<nav className="flex px-8"><a href="/">Home</a></nav>');

// To DSL (default)
compile(ast, { target: 'dsl' });
// → '[nav.flex.px-8|[a{href=/}|Home]]'

// To React JSX
compile(ast, { target: 'react' });
// → '<nav className="flex px-8"><a href="/">Home</a></nav>'

// To plain HTML
compile(ast, { target: 'html' });
// → '<nav class="flex px-8"><a href="/">Home</a></nav>'

Integration Patterns

🤖 AI Prompt Compression

The primary use case — compress UI before sending to an LLM to save tokens and cost, then expand the response back:

import { compressToDSL, expandFromDSL } from '@aimata-dsl/core';

async function editComponentWithAI(jsx, instruction) {
  // Compress before sending — saves ~50% tokens
  const dsl = compressToDSL(jsx);

  const response = await fetch('/api/ai', {
    method: 'POST',
    body: JSON.stringify({
      messages: [{
        role: 'user',
        content: `Edit this component (Aimata DSL format):
${dsl}

Instruction: ${instruction}

Reply with ONLY the modified DSL.`
      }]
    })
  });

  const { dslReply } = await response.json();

  // Expand AI's DSL response back to JSX
  return expandFromDSL(dslReply, 'react');
}

🎨 Design Token Extraction

Parse any component tree and extract all Tailwind classes for analysis or theming:

import { parse } from '@aimata-dsl/core';

function extractTokens(jsx) {
  function walk(nodes) {
    return nodes.flatMap(n =>
      n.type === 'text' ? [] : [...n.classes, ...walk(n.children)]
    );
  }
  return [...new Set(walk(parse(jsx)))]; // deduplicated
}

extractTokens(myComponent);
// ['flex', 'gap-4', 'rounded-xl', 'bg-blue-500', 'text-white', ...]

// Count usage of each class across multiple components
const usage = components.flatMap(c => extractTokens(c))
  .reduce((acc, cls) => ({ ...acc, [cls]: (acc[cls] || 0) + 1 }), {});
// { 'flex': 14, 'rounded-xl': 8, 'bg-blue-500': 3, ... }

⚡ Cross-Framework Output

Maintain one DSL source, export to multiple frameworks:

import { compressToDSL, expandFromDSL } from '@aimata-dsl/core';

// Store DSL as your source of truth
const BUTTON_DSL = '[button.px-4.py-2.bg-blue-600.text-white.rounded-lg{onClick=fn}|Click]';

// Export to any target on demand
const reactOutput = expandFromDSL(BUTTON_DSL, 'react');
// <button className="px-4 py-2 bg-blue-600 text-white rounded-lg" onClick={fn}>Click</button>

const htmlOutput  = expandFromDSL(BUTTON_DSL, 'html');
// <button class="px-4 py-2 bg-blue-600 text-white rounded-lg" data-onclick="fn">Click</button>

Error Handling

import { compressToDSL, expandFromDSL } from '@aimata-dsl/core';

// compressToDSL errors
try {
  compressToDSL('');             // TypeError
  compressToDSL(null);           // TypeError
  compressToDSL('<div');         // SyntaxError: Unclosed tag
} catch (e) {
  if (e instanceof TypeError)  console.error('Invalid input:', e.message);
  if (e instanceof SyntaxError) console.error('Parse error:', e.message);
}

// expandFromDSL errors
try {
  expandFromDSL('');               // TypeError: expects non-empty DSL string
  expandFromDSL('[div]', 'vue');  // TypeError: target must be 'react' or 'html'
} catch (e) {
  console.error(e.message);
}

FAQ

Does it work in the browser without bundling?
Yes. Import it via a CDN or local path using <script type="module">: 
<script type="module">
  import { compressToDSL } from 'https://cdn.jsdelivr.net/npm/@aimata-dsl/core/src/index.js';
  console.log(compressToDSL('<div className="flex">Hi</div>'));
</script>
Is the compression lossless?
Yes — compressToDSL(expandFromDSL(dsl)) always equals the original DSL. All structural information (tag, id, classes, props, children) is preserved exactly. Whitespace between tags is normalized.
Does it support TypeScript generics or complex JSX expressions?
The parser handles well-formed JSX tags and string/identifier prop values. Complex inline TypeScript generics or multi-line JSX expressions inside props (e.g. children={(x) => <div>{x}</div>}) are not supported — use parse() on the outer structure and handle those props manually.
How does it handle PascalCase React components?
They're classified as type: 'component' in the AST and preserved as-is in React output. In HTML output ('html' target), PascalCase tags are lowercased to <div> as a fallback.
Can I use this with CommonJS (require)?
The package is ESM-only. For CJS projects, use dynamic import: 
const { compressToDSL } = await import('@aimata-dsl/core');
What's the typical token reduction?
2–3× for typical Tailwind-heavy components. A 580-character JSX button with many classes compresses to ~220 characters — roughly a 48% reduction in characters, and even more in LLM tokens since the DSL avoids repeated patterns like className=, quotes, and tag-pair verbosity.
