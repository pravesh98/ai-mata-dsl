// How it works

Three steps, one pipeline

01
⬇

Parse

Your JSX or HTML is tokenized and walked into a lightweight AST — no Babel, no external parsers.

parse(source) → ASTNode[]
→
02
⬡

Compress

The AST is serialized into the bracket micro-DSL. Tags, IDs, classes, props, and children — all encoded losslessly.

compressToDSL(code) → string
→
03
↑

Expand

Expand back to production React JSX or plain HTML. Deterministic — compress → expand → compress gives identical DSL.

// API Reference

Full API

compressToDSL(code: string): string

Converts JSX or HTML source into Aimata micro-DSL notation. Accepts any well-formed JSX/HTML string.

import { compressToDSL } from '@aimata-dsl/core';

compressToDSL('<div className="flex gap-4">Hi</div>');
// → '[div.flex.gap-4|Hi]'
expandFromDSL(dsl: string, target?: 'react' | 'html'): string

Expands micro-DSL back to JSX or HTML. React mode uses className/{fn}. HTML mode uses class/data-on*.

import { expandFromDSL } from '@aimata-dsl/core';

expandFromDSL('[button.btn{onClick=go}|Click]', 'react');
// → '<button className="btn" onClick={go}>Click</button>'

expandFromDSL('[button.btn{onClick=go}|Click]', 'html');
// → '<button class="btn" data-onclick="go">Click</button>'
parse(source: string): ASTNode[]

Tokenizes and parses JSX/HTML into a plain-object AST. Useful for custom analysis, class extraction, or tooling.

import { parse } from '@aimata-dsl/core';

const [root] = parse('<div className="flex"></div>');
root.tag;     // 'div'
root.classes; // ['flex']
compile(ast: ASTNode[], opts?: { target: 'dsl' | 'react' | 'html' }): string

Compiles an AST directly to any target. Skips the parse step when you already have an AST from parse().

import { parse, compile } from '@aimata-dsl/core';

const ast = parse('<nav className="flex"></nav>');
compile(ast, { target: 'dsl' });   // '[nav.flex]'
compile(ast, { target: 'html' });  // '<nav class="flex"></nav>'

Built for AI workflows

AI Prompt Compression

Send DSL to your LLM instead of raw JSX — 2-3× fewer tokens, lower cost, same information.

// Compress before sending to AI
const prompt = `Edit: ${compressToDSL(myUI)}`;

// Expand AI's DSL response
const updated = expandFromDSL(aiReply, 'react');
🎨

Design Token Extraction

Parse any component and extract all classes, IDs, and props programmatically.

const [root] = parse(myComponent);
const tokens = root.classes;
// ['rounded-xl', 'shadow-lg', 'p-6', ...]
⚡

Cross-Framework Output

Write once in DSL, export to any framework. React, plain HTML, and more targets coming.

const dsl = compressToDSL(reactComp);
expandFromDSL(dsl, 'react');  // JSX
expandFromDSL(dsl, 'html');   // HTML
